# Safique Ahamed Landing Page

This project contains a landing page hero section for Safique Ahamed.

## Files

- `index.html` - main landing page
- `profile-icon.jpg` - profile image used in the navbar

## Features

- Sticky header
- Smooth scroll and reveal animations
- Vimeo video embed inside a macOS-style showcase frame
- Moving badge section
- Responsive layout

## Deploy

Upload the files to your GitHub repository root and enable GitHub Pages from repository settings.
